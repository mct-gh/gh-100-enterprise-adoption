# 엔터프라이즈 지원과 도입

_회사 규모로 GitHub 을 굴릴 때 관리자가 실제로 하는 일을 다룹니다. GH-100 모듈 7 실습입니다._

## 이 실습은

- **대상**: GitHub 을 회사 표준으로 들여오거나 운영하는 사람
- **배우는 것**: EMU 도입 판단, 관리자와 GitHub Support 의 경계, 지원 요청에 붙일 진단 정보
- **만드는 것**: 도입 계획서, 지원 경계 판단표, 진단 아티팩트 하나
- **걸리는 시간**: 15분
- **선행**: [Introduction to GitHub](https://github.com/skills/introduction-to-github)

이 실습에서 하는 일

1. EMU 도입 계획을 적는다
2. 내가 풀 문제와 GitHub Support 로 보낼 문제를 가른다
3. 진단 정보를 모아 아티팩트로 남긴다
